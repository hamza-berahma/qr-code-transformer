# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2024

### Added
- Initial release
- QR code transformation with minimal module changes
- Support for all ECC levels (L, M, Q, H)
- Dual algorithm support (QArt and ILP)
- Automatic ECC level optimization
- Web interface (FastAPI)
- Desktop GUI (Tkinter)
- Comprehensive test suite
- CI/CD with GitHub Actions

### Features
- Transform QR(A) to decode as message B with minimal changes
- Exploit Reed-Solomon error correction non-bijectivity
- Test all 4 ECC levels automatically
- Compare QArt and ILP algorithms
- Select best combination automatically
- Visualize transformations
- Detailed insights and statistics
